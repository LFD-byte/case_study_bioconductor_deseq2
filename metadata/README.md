# metadata

What each data file is and where it came from.

## airway dataset

- Source: Bioconductor package `airway`, loaded with `data(airway)`; no file is downloaded into `data/raw/`.
- Study: Himes et al. 2014, PLoS ONE 9(6):e99625, doi:10.1371/journal.pone.0099625.
- Samples: human airway smooth muscle cells, treated with dexamethasone or untreated.
- Checksums: none, because the data comes from the versioned package rather than project files.

## Abbreviations

- `dex`: dexamethasone treatment (`trt` treated, `untrt` untreated).
- `cell`: cell line.
- `padj`: adjusted p-value.
- `log2FC`: log2 fold change.
