## 背景与理解

bioconductor 诞生于 2004 年，当时人们越来越意识到许多生物过程的计算本质，以及计算和统计模型的巨大应用价值。其次，高通量数据采集技术的进步对生物学研究流程的每个阶段都提出了更高的计算和统计要求。Bioconductor 项目的主要目标是创建一个持久且灵活的软件开发和部署环境，以应对这些新的概念、计算和推断方面的挑战。

## 识别开放实践

Bioconductor 诞生之初就关注可重复研究这一问题，在计算机辅助生物技术（CBB）领域，发表文章所依据的数据正逐渐成为一种常态。这种做法提供了可重复研究所需的要素之一——数据访问权限。另一个重要要素是获取用于转换数据的软件以及用于生成论文结论所依据的输出结果的明确指令或命令。R 语言成熟的平台独立性与 Bioconductor 的打包和文档标准相结合，形成了一个系统，该系统能够以可运行的代码和脚本分发数据，从而满足 CBB 领域可复现和可重现研究的大部分需求。bioconductor 高度符合 FAIR 原则（可发现 Findable、可访问 Accessible、可互操作 Interoperable、可重用 Reusable）

每个正式发布的 Bioconductor 软件包都会获得一个专属的官方 DOI 和固定的落地页 URL。并且强制要求开发者在元数据（DESCRIPTION 文件）中使用标准化的 biocViews 层次分类标签（涵盖基因组学、单细胞、蛋白质组等），方便人类和机器检索。这些措施使 bioconductor 满足了可发现性。

bioconductor 的所有软件包、源代码和文档均可通过标准的 HTTPS 协议、R 命令行工具（BiocManager::install()）以及 Git 版本控制系统（git.bioconductor.org）免费、无障碍获取，无需特殊权限。即使某个软件包因不再维护而被弃用（Deprecated）或移除，其历史版本、元数据和代码归档依然保留在官方服务器中，确保旧文献分析流程的可追溯性。
这些措施保证了 bioconductor 的可访问性。

Bioconductor 强制推广共享的核心数据容器——如基因组区间用 GRanges、测序矩阵用 SummarizedExperiment、单细胞数据用 SingleCellExperiment、质谱数据用 Spectra。这使得不同团队开发的数百个软件包可以无缝串联，无需反复转换格式。并且原生支持生信领域的标准文件格式（BAM、VCF、GFF、FASTQ、HDF5 等）。这些措施是 bioconductor 可互操作性的保证。

Bioconductor 要求所有入库软件包声明明确的开源协议（如 Artistic-2.0、GPL、MIT 等），保障代码的合法复用与修改。并且强制要求每个包提供包含真实可执行代码的教程文档（Vignettes），展示完整的生物学分析工作流，而不仅仅是孤立的函数说明书。这些保证了 bioconductor 的可重用性。

## 基于证据评估影响

bioconductor 目前已经开发到了 3.23 版本，总共有 3818 个包，初始论文被引用为 15311。DESeq2 是 Bioconductor 生态系统中最核心的 R 包之一，专门用于高通量测序数据（如 RNA-seq）的差异表达分析，目前和 bioconductor 都是 3.23 版本，是如今差异表达分析的常用工具，已有 1246 个引用。

## 批判性讨论局限

对于可复现的科学研究来说，bioconductor 目前有以下几个问题。首先 Bioconductor 的版本必须与 R 的大版本严格对应。例如，如果你想使用最新版本的某个 Bioconductor 包，你必须将整个 R 环境升级到最新版。如果你使用的是旧版 R，BiocManager::install() 会默认安装旧版的 Bioconductor 包，有时这意味着你无法使用作者刚刚修复了 Bug 或增加了新功能的新版本。其次，许多 Bioconductor 包包含底层的 C++ 或 Fortran 代码。在 Linux 服务器或新版 Mac 芯片上，经常需要从源码编译，耗时极长，且经常因为系统缺少某个底层库而报错中断。最后，在网络不佳的环境下，通过 R 终端下载这些大文件极易中断，导致安装失败或数据损坏，即使满足了可访问性，也由于现实原因安装 R 包失败。

## 实际探索开放资源

我们使用 Bioconductor 自带的 airway 数据集作为示例，数据集是人气道平滑肌细胞，有地塞米松处理和未处理两种处理方式，使用 conda 安装 R 环境和 bioconductor 包。通过 DESeq2 比较处理组与未处理组的基因表达差异，先保留至少 4 个样本中 count ≥ 10 的基因（共 16,139 个），再运行 DESeq() 进行差异检验，并以 padj < 0.05 且 |log2FC| > 1 为阈值筛选差异基因。结果显示，共有 4,081 个基因的 padj < 0.05（上调 2,190 个，下调 1,891 个），其中 951 个同时满足倍数变化阈值（上调 490 个，下调 461 个）PCA 显示，PC1 解释了 48% 的方差，并将处理组与未处理组完全分开，说明地塞米松处理是样本间表达差异的主要来源。具体的代码和运行结果已经上传到 github 仓库 [case_study_bioconductor_deseq2](https://github.com/LFD-byte/case_study_bioconductor_deseq2)。我计划将该 deseq2 包应用于我分析的组学数据。
